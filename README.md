# Mandala Adventures

Adventure travel site for Nepal, Himalayas, and Asia expeditions. Built for Zac & Luke Larsen — trade for NAPCO website work.

**Live:** [mandalaadventures.com](https://www.mandalaadventures.com)

---

## Stack

- **Next.js** — TypeScript, App Router
- **Tailwind CSS v3** — Styling
- **Framer Motion** — Animations
- **Vercel** — Hosting, auto-deploy from `main`

## Development

```bash
npm install
npm run dev     # localhost:3000
npm run build   # production build
```
